# Work

Run scripts from this folder (`Work/`).

## Training (four terminals)

Use **four separate terminals**, each `cd` into `Work/` (Git Bash or WSL on Windows).

Run **`run_no_plr_5x.sh` in two terminals** and **`run_plr_5x.sh` in two terminals** (each script twice, one run per terminal):

| Terminal | Command |
|----------|---------|
| 1 | `bash run_no_plr_5x.sh` |
| 2 | `bash run_no_plr_5x.sh` |
| 3 | `bash run_plr_5x.sh` |
| 4 | `bash run_plr_5x.sh` |

That is **four terminals total**: two for no-PLR batches and two for PLR batches.
